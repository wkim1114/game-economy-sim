# Game Economy Simulation

> A small simulation exploring how currency sources, sinks, and player behavior shape a game economy.

## Status

🚧 **Work in progress.** Early stage: scope and design are being developed.

## Overview

Game economies depend on a balance between how players earn currency (sources) and how they spend or lose it (sinks). This project builds a simple simulation to see how that balance, and different kinds of player behavior, affect the economy over time.

## Planned Scope

- [ ] Define a simple in-game economy (currency, sources, sinks)
- [ ] Model basic player behavior types (e.g., savers and spenders)
- [ ] Simulate many rounds and track key metrics (currency supply, prices, player balances)
- [ ] Compare scenarios and visualize the results
- [ ] Write up findings
